# 오픈소스 스카우트

사용자 원칙
- 직접 개발보다 요즘 뜨는 **무료** 오픈소스(스킬·MCP·도구)를 가져다 쓰는 게 빠르다.
- **설치 즉시 무료로 쓸 수 있는 것(API 키·유료 결제 불필요)** 을 최우선으로 한다. 키가 필요한 건 대안이 정말 없을 때만, 그 사실을 분명히 표시해서 제안한다.
- 하나 찾았다고 끝내지 않는다. **조건에 맞는 걸 찾을 때까지** 조사한다.
- 사용자는 비개발자다. 결과는 쉬운 말로 짧게.

## 1단계: 조사 기획 (시작 전 30초)
`search-strategy` 스킬 방식으로 먼저 계획을 세운다. 머릿속으로만 하지 말고 짧게 적어둔다.
1. **진짜 필요한 것 한 줄**: "무엇을 할 수 있어야 하나" (예: "릴스 링크 → 대본/장면 추출, 키 없이")
2. **합격 조건 체크리스트**: 무료·키 불필요 / Windows 동작 / 최근 3개월 내 업데이트 / 인기(별·설치 수) / 공식 또는 원본 저장소 / 우리 작업에 실제로 맞음
3. **검색어 묶음 6~12개** — 한 단어로만 찾지 않는다:
   - 같은 뜻 다른 말 (clone / remake / replicate / recreate, viral / trending)
   - 형식별 (`skill`, `mcp`, `claude code`, `agent`, `cli`, `open source`)
   - 언어별 (영어 + 한국어 + 중국어 — 중국 커뮤니티에서 먼저 뜨는 경우가 많다)
   - 도구 이름이 들리면 정확한 이름으로 (예: "hypit")
4. **찾을 곳 목록**: 아래 2단계의 소스 중 어디를 돌지 정한다.

## 2단계: 넓게 훑기 (여러 소스, 가능하면 동시에)
여러 소스는 서로 독립적이므로 한 번에 병렬로 돌린다. 범위가 넓으면 Agent(Explore/general-purpose)를 2~3개 나눠 띄워 소스별로 맡긴다.

| 소스 | 방법 (모두 무료) |
|---|---|
| 이미 설치된 것 | `~/.claude/skills`·`~/.agents/skills`(Codex) 목록, `claude mcp list`, `claude plugin list`, `codex mcp list` |
| 스킬 레지스트리 | `npx -y skills find "<검색어>"` (find-skills) — 설치 수 확인 |
| GitHub 인기순 | WebFetch `https://api.github.com/search/repositories?q=<검색어>&sort=stars` |
| GitHub 최근 급상승 | `...?q=<검색어>+created:>YYYY-MM-DD&sort=stars` (오늘 기준 60~90일 전), trendshift.io |
| 커뮤니티 화제 | `last30days` 스킬 (무료: Reddit, YouTube, Hacker News, GitHub, Polymarket) |
| 유튜브 | `yt-dlp --flat-playlist -J "ytsearch20:<검색어>"` 로 조회수 높은 영상 → `baoyu-youtube-transcript`로 내용 확인 |
| 릴스/틱톡/X/웹 | `playwright` MCP 로 실제 브라우저처럼 열어보기, `baoyu-url-to-markdown` |
| 공식 문서 | 회사 공식 사이트·docs·GitHub org |
| 사실 확인이 중요한 조사 | `research` 스킬 (1차 출처 위주로 정리) |

## 3단계: 좁히기 (후보 표 만들기)
후보마다 합격 조건을 체크한다. 숫자는 직접 확인한 것만 쓴다(블로그 숫자는 "출처 기준"으로 표시).
- 공식 원본인가? (복사본·백업 저장소 제외)
- 무료로 바로 되나? README에서 "API key", "token", "credits", "paid" 를 꼭 확인
- 최근 업데이트, 별/설치 수, 이슈에 "Windows" 문제가 많은지
- 수상한 설치 스크립트·과한 권한 요구 → 제외

## 4단계: 계속할지 판단 (멈춤 규칙)
다음 중 하나가 될 때까지 검색어를 바꿔 2단계를 반복한다 (최대 3바퀴):
- ✅ 합격 조건을 모두 만족하는 후보가 **2개 이상** 나옴 → 비교해서 추천
- ✅ 새 검색을 해도 **이미 본 후보만 계속 나옴** (포화) → 지금 결과로 결론
- ⚠️ 3바퀴 후에도 무료 후보가 없음 → "무료로는 이게 최선, 키 있으면 이것" 으로 정직하게 보고

반복할 때 바꿀 것: 검색어 동의어/다른 언어, 다른 소스, 찾은 후보의 README 속 "Related / Alternatives / Inspired by" 목록, awesome-리스트(`awesome <주제>`).

## 5단계: 직접 확인
추천 1순위는 설치해서 **한 번 실제로 돌려본다** (간단한 테스트 한 줄). 안 되면 2순위로 넘어간다.
설치는 전역으로: `npx -y skills add <owner/repo> -g -a claude-code --skill '*' -y --copy`
MCP는 `claude mcp add --scope user ...` (Codex 도 쓰면 `codex mcp add ...` 도. 키는 환경변수 이름만)

## 6단계: 짧게 제안
> 🔎 찾아봤어요 (검색 ○바퀴, 후보 ○개 중)
> 1. **이름** — 한 줄 설명 · ⭐ 숫자 · 무료/키 필요
> 2. ...
> 추천: 1번 (이유 한 줄). 설치하고 테스트까지 해뒀어요 / 설치할까요?

- 무료이고 공식/인기 확실한 스킬·MCP는 바로 설치해도 된다 (설치 후 한 줄 보고).
- 유료 결제, 계정 연결, 시스템 전체를 바꾸는 설치는 먼저 물어본다.

## 기록
`~/.claude/skills/oss-scout/discoveries.md` (Codex 에서도 이 파일 하나를 같이 쓴다) 에 한 줄씩: `날짜 | 이름 | 무엇 | 무료? | 결과(좋음/별로/이유)`. 다음 조사 때 먼저 확인한다.
